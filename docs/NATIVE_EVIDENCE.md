# Pewbeam native evidence

Analyzed the uploaded app's extracted ARM64 Mach-O statically. Binary: `extracted/Pewbeam/Pewbeam.app/Contents/MacOS/Pewbeam`, SHA-256 `6118e46780eb424666bdbcbaa96ae6f34d5267a83017e44c1d795eaca53150e2`. Line references below refer to `native-strings.txt`. Hex offsets are file offsets in that Mach-O, not virtual addresses. Strings and surviving Rust symbol fragments establish included capabilities, names, and diagnostic branches; they do not demonstrate which branch ran, recover exact constants, or verify runtime accuracy.

## Search paths

- **Several complementary searches are included.** A command-registration string contains `search_verses`, `search_verses_semantic`, `search_verses_direct`, `search_verses_shingle`, and `search_verses_text` (line 101379; `search_verses_semantic` at `0x1af5ec3`). Serialized `TextSearchMode` labels include `fuzzy` and `verbatim` (101620). Diagnostics distinguish direct, shingle, and semantic failures (51969–51988).
- **Explicit references receive priority in live detection.** Diagnostics suppress narrative, shingle, and semantic results when the active utterance already has a direct reference, including the race where that reference arrives while another search is running (101256–101276; first direct-reference suppression at `0x174c253`). Rust symbol fragments include `extract_bible_reference`, loose/disordered references, explicit verse ranges, contextual verse callouts, pending book/reference state, and `apply_stt_corrections` (504953–505011). These are evidence of multiple reference-parsing paths, not a recovered complete grammar.
- **Quote matching has an indexed shingle path.** `src/services/shingle_index.rs` (51038), `ShingleIndex` build/search/tokenize symbol fragments (463150–463151, 463310, 469510), and log templates `verses, kept strong`, `rescue`, `postings (cap`, `per list)` (51267–51271) show an index with posting-list pruning. N-gram sizes, scoring weights, and caps remain unknown.
- **Native semantic retrieval includes local neural embeddings plus lexical ranking.** Included paths are `onnx_models/embeddinggemma/onnx/model_q4.onnx` (`0x1955694`), tokenizer JSON, `vectors/verses_mapsorted_f32.bin` (`0x194de19`), and verse maps (74658). Model inputs/outputs include `input_ids`, `attention_mask`, `sentence_embedding` (74626). Surviving symbols identify `SemanticIndex::retrieve`, `lexical_tokenize`, `Bm25::build/search`, `ScoredCandidate`, and `re_rank` (482533, 482585, 501608, 507178, 517609–517660). Together this supports a local semantic-plus-lexical design, but does not prove the fusion formula, vector distance, dimensionality, or BM25 parameters.
- **A cross-encoder reranker is an additional optional stage.** ONNX `model_int8.onnx`, `tokenizer.json`, input IDs/masks/type IDs, and logits (101307), plus `cross_encoder_miniLM/onnx/model_info.json` (101317; `0x1af1781`). Diagnostics say it can background-install a `cross-encoder` pack and activate on the next tick (101287–101288, 101316). Failure logs explicitly say queue reranking is disabled “fail-open” or falls back to `re_rank` order (51173–51178, 51322–51323).
- **Live detection is bounded and deduplicated.** Included diagnostics suppress unchanged recent queries, saturated concurrency, same top verse, and cross-path duplicates (101264–101276, 51523–51535). Symbols identify sliding windows, terminal windows, utterance search, query cleanup, and `SEMANTIC_SEARCH_PERMITS` (504963–504984). The live paraphrase path can fall back to full semantic search when empty, and that fallback has a timeout (101414–101422; 51518–51520). Exact timeout, concurrency, thresholds, and debounce values are not established.
- **Search caching exists.** Cache-hit logs distinguish ordinary native and live-paraphrase search (74237–74247); cache eviction labels explicitly reference TTL and LRU capacity (50399–50403). No concrete limits recovered.
- **Native/Python fallback is intentional.** Native load failure says `using Python fallback` (`0x17403c5`, lines 50397–50399); `PEWBEAM_NATIVE_SEMANTIC`, missing embedding directory, or unavailable English index have fallback diagnostics (101432–101435). “FAISS” appears in direct/semantic diagnostics (51969, 51987–51990); this alone does not establish that the native index itself uses FAISS.

## Local and remote services

- Local resource paths and ONNX execution labels support offline-capable search after needed assets are installed. They do not establish that all assets were shipped or installed in this particular copy.
- Online speech recognition is separately represented by Deepgram proxy/session URLs and `wss://api.meta.ai/v1/asr/realtime` (74233, 74259, 101228). `whisper-native`, `mlx-whisper`, and offline labels also exist (101228, 101632). No provider credential values were inspected or copied.
- Structured “scripture decision” candidates/results include reference evidence, provider/model/prompt versions, `selected`/`abstained`/timeouts/errors, budgets, circuit state, and projection intent (101176–101181). That is evidence of an optional provider-mediated decision subsystem, not proof it is enabled or a basis for claiming every query is sent remotely.
- This bounded inspection found no app-specific SQL/FTS schema or query proving SQLite is the search store. JSON translation and vector paths are present. Do not infer a database engine merely from generic dependencies.

## Plans and other included capabilities

- Serialized native tier labels are **`free`, `plus`, `core`** (74231; contiguous `freepluscore` at `0x194c621`), with a separate `has_plus_addon`. This native evidence does **not** establish a “Premium” branded plan. The sole lowercase `premium` match in the bounded native string area was generic embedded text, not licensing evidence.
- Usage fields explicitly track minutes, searches, and AI slides used/limit (74230–74231; 101620). They establish usage counters, not the numeric limits.
- Entitlement names are `no_watermark`, `all_themes`, `unlimited_session`, `multi_device`, `advanced_ai`, `sermon_notes`, and `original_languages` (101620; entitlement string at `0x1af9e8c`). There is no verified per-tier entitlement matrix in these native strings.
- Command and type names cover microphone/STT, transcripts/history, word-study lookup/alignment, translation/language packs, presentation import and live slide decks, still/video backgrounds, themes/design rendering, multiple output channels and mirrors, blackout/alerts, HDMI windows, NDI, Syphon, DeckLink, OSC controls, broadcast HTTP API, and publishing sessions (101379, 101620–101641). These are a capability inventory, not proof every feature is functional on every platform or entitled in every plan.

## Remaining gaps

Exact ranking weights, shingle lengths, semantic cutoffs, numeric quotas, current prices, server-side entitlements, runtime behavior, macOS hardware outputs, and provider availability need stronger evidence. Bundled frontend code may clarify UI flow and plan gates; native execution or controlled traces on macOS would be needed to verify observed user behavior. No licensing mechanism was changed, no credentials used, and no proprietary source was copied into the new app.
