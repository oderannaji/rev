## Exact evidence anchors

Source files remain in `/workspace/pewbeam-analysis`; existing extraction and analysis were not repeated.

- **Neural search:** `native-strings.txt` lines 74626 and 74658 contain the input/output names and `onnx_models/embeddinggemma/onnx/model_q4.onnx`, plus vector paths. Lines 101307–101317 identify the optional MiniLM reranker. See [native report](NATIVE_EVIDENCE.md) for file offsets and retrieval symbols. The exact upstream checkpoint revision, fusion formula and live model availability remain unverified.
- **Offline engine:** `native-strings.txt` line 55063 contains `whisper-rs-0.16.0/src/whisper_state/segment.rs`; line 55422 contains the compiled `whisper.cpp/src/whisper.cpp` source path. Line 101308 includes `ggml-large-v3-turbo-q5_0.bin`, `ggml-small-q5_1.bin`, `whisper-ggml-turbo` and `whisper-ggml-small`. These are available code/model references, not proof which model was installed or selected. The frontend at `index-readable.js:58253` uses the `whisper-ggml-` offline pack prefix and download/install status UI.
- **Online speech is separate:** Deepgram and Meta realtime ASR paths, and `mlx-whisper` labels, are recorded in [native evidence](NATIVE_EVIDENCE.md). Their presence does not establish the active online provider or default offline engine.
- **NDI:** `native-strings.txt:74658` includes `NDIlib_initialize`, `NDIlib_send_create`, `NDIlib_send_destroy`, and `NDIlib_send_send_video_async_v2`. Line 101068 contains `libndi.dylib` and `libndi.5.dylib` runtime search paths; line 101310 includes `NDIlib_find_create_v2` and `NDIlib_recv_create_v3`. This establishes native sender/receiver integration paths, not a verified installed SDK version, codec variant or successful stream.
- **Drafting model:** `index-readable.js:40393` declares the Pewbeam-hosted `/api/openai` endpoint; lines 40394–40395 set `HD` and `Px` to `gpt-4.1-mini`. The following request helper submits `model: r.model ?? HD` with chat messages. This is the bundled Content Studio default; the server may override it, and it does not identify every AI feature's model. Shepherd Pro never calls that vendor endpoint.

## Suggested order

Implement and evaluate neural retrieval first, then local speech and speech-to-scripture matching. Configure drafting using the owner's chosen provider. Add the native NDI bridge against the official SDK and test both sender and receiver on the actual network. Validate the combined build on the Mac before signing a distributable installer.

The first useful owner reply is: **Mac chip / RAM / macOS; spoken languages; streaming software or NDI receiver; transparent lower thirds yes/no; AI local or cloud.** API secrets belong in local server configuration, not chat or source control.
